# AR.Angrek

AR.Anggrek merupakan skripsi saya yang bekerja dengan mengklasifikasikan 5 genus anggrek (Cattleya, Dendrobium, Oncidium, Phalaenopsis, dan Vanda) yang kemudian dapat menampilkan augmented reality secara objek 3D dan menampilkan informasinya
Klasifikasi menggunakan CNN MobileNetV2
Bahasa pemrograman yang digunakan untuk membuat model yaitu Python
Bahasa pemrograman yang digunakan untuk membuat aplikasi yaitu C#
